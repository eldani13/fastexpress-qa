# FastExpress QA

Repositorio del Analista de Calidad: plan de pruebas, defectos, reportes, métricas ISO 9126 y trazabilidad.

## Repos del proyecto

| Rol | Repositorio |
|---|---|
| API | https://github.com/eldani13/fastexpress-api |
| Frontend | https://github.com/eldani13/fastexpress-frontend |
| QA | https://github.com/eldani13/fastexpress-qa |

## Contenido

- `docs/qa/` — plan, casos, defectos DEF-001…006, sesiones exploratorias, reportes, bitácora
- `docs/calidad/` — plan de calidad, métricas, trazabilidad
- `docs/proceso/` — ciclo de vida de defectos y plantillas de actas
- `.github/ISSUE_TEMPLATE/` — plantilla de reporte de defecto

Los Issues de defectos se gestionan en este repositorio.
