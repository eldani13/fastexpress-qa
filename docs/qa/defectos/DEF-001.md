# DEF-001: la API responde 404 en lugar de 405 a un método no permitido

| Campo | Detalle |
|---|---|
| Estado | **Cerrado** |
| Issue | #__ (registrado después de la corrección; ver nota) |
| Módulo | Backend (`app/main.py`) |
| Severidad / prioridad | Media / Alta |
| Detectado | 2026-10-12, prueba automatizada `test_metodo_no_permitido` al integrar el frontend |
| Corregido | 2026-10-12 (ADR-005) |
| Prueba de regresión | `test_frontend_servido_sin_ocultar_la_api` |

## Pasos para reproducir (versión con el defecto)

1. Iniciar el servidor con la carpeta `frontend/` presente.
2. Enviar `GET /api/v1/cotizaciones`.

**Esperado:** `405 Method Not Allowed`. **Obtenido:** `404 Not Found`.

## Causa raíz

El frontend se montó con `StaticFiles` en `/`. Si una petición coincide en ruta pero no en método,
el enrutador sigue buscando y el montaje en `/` la captura como un archivo inexistente.

## Corrección y verificación

El frontend se sirve en `/app/` y `/` redirige ahí. Suite completa aprobada después del cambio.

**Nota:** este defecto se encontró y corrigió durante la integración inicial, antes de que existiera
el repositorio. Se registra como issue para que el historial quede completo.
